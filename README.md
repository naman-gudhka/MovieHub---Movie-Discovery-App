# MovieHub - A Movie discovery application.

# Description:
  A MovieHub is a responsive web-based application which lets the user to discover the movies. The application lets the user to search movies, add the movies to user's watchlist and the favourites, etc. The application contains a user-friendly UI/UX.

# Tech Stack:
  1.HTML5
  2.CSS3
  3.Vanilla JavaScript
  4.Local Storage (Browser Storage API)
  5.TMDB API
  6.Git & Github for version control
  7.VS Code & Live server for development
